# Changelog

## 1.0.0

- Initial release. The Orb C.A.R.T. moves here from the OrbCart mod (last version 1.0.7), which is now deprecated. Same cart, price and behaviour, except the screens: the handle screen now shows the orbs' total value and a new far-end screen shows how full it is; settings are now in `BepInEx/config/HatterCartsPack.cfg`, section `[Orb C.A.R.T.]`, with a new `Enabled` switch.
- New cart: the C.A.R.T. Plus, 40% wider and longer and 10% taller than the C.A.R.T. (walls just as thick). Its stasis button, at the far end opposite the handle, shrinks the cart and everything in it (players too) back to normal C.A.R.T. size for as long as it's held (no cooldown) so it fits through tight doors; it grows back once there's room.
- Built against R.E.P.O. v0.5.0 and REPOLib 4.3.0.
