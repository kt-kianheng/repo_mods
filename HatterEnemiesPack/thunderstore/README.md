# Hatter Enemies Pack

New enemies, new fun ways to screw with your friends :D.
I know there are already a lot of mimic mods, but this one has my own twist to it, can read the details below or...skip it to not get spoiled.

## Alter Mimic (tier 2, multiplayer only)

Tier 2 monster
An invisible stalker. It waits for a player to be alone in a room, creeps up on them and silently latches on: from then on nobody else can hear that player's voice (their text-to-speech still works). Then it shows up somewhere near the rest of the team, wearing the latched player's face as their dead head, or take their form entirely.

### Dead Head Form

- Get possessed exactly how a player would press [E] when dead, jumps around and uses TTS.
- When placed in a cart or extraction point, vibrates every few second, then release a pulse that pushes valuables out.
- When in the state where it pulses, if players touch it again, it will countdown and then explode, damage everything nearby.

### Semibot Form

- Walks, run, jump, and tumbles around like any semibot would.
- Uses TTS to confuse you
- After being alive for some time and being around a player, it will whip out its own weapon and shoot. Warning: it can be quite an... aimbot.
- Can grab valuables occasionally, but is very careless. Don't let it touch your valuables.
